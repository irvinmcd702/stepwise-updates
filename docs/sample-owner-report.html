How every step was checked

  1. Before each update, a full copy of the site's files and database was saved.
  2. After it, the key pages were opened in a real browser: home, menu, visit, contact and the login page.
  3. Each page was compared picture-by-picture with the last version that was known to be good.
  4. A test message was sent through the contact form and had to arrive in the mailbox.
  5. The server's error log was read for anything new.
  6. If anything failed, the saved copy went back in place, and the same checks confirmed the site was exactly as before.
